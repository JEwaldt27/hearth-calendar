Self-hosted family calendar

Your family’s week, on the wall.

Hearth brings everyone’s calendars, chores, groceries and dinner plans together on a wall tablet, every phone and any browser. It runs on your own server, so there’s no subscription and no one else’s cloud.

Yours, not rented

Your family’s schedule stays in your house.

Hearth runs in Docker on a home server, a Raspberry Pi or a small VPS. There’s no account with us, because there is no “us”.

No subscription
Free to run. The code is on GitHub for anyone to read.
Accounts for everyone
Each adult gets their own login and decides which calendars to share, and with whom.
Nightly backups
The database is backed up every night, and a script can copy the backups to your PC.
Looks after itself
A health page for admins, plus an email or push alert if backups stop, sync breaks or the disk fills up.
Private by design
Linked-account passwords and tokens are encrypted. Wall displays use revocable links, not passwords.
Install

Up and running in about five minutes.

Run one command

On a Linux machine that’s always on, paste the install command below. It sets up Docker, generates the secrets and downloads Hearth.

Answer two questions

Home network only, your own domain with HTTPS, or a Cloudflare Tunnel? And which time zone is home?

Create your account

Open the address it prints, for example http://192.168.1.50:8080. The first account becomes the admin.

Questions

Good to know

Something else? Ask on GitHub.

What do I need for the wall display?

Any screen with a modern web browser. An older iPad or Android tablet works well, and so does a monitor with a Raspberry Pi. The display does very little work, so a secondhand tablet is plenty. Create a display link in Settings and open it on the device.

Do I need a domain name?

No. Hearth works on your home network straight away. For use away from home, installing it as a phone app, push reminders, and linking Google or Outlook, you’ll want HTTPS. The installer can set that up with your own domain or a free Cloudflare Tunnel.

Which calendars can I connect?

Google, Outlook.com and Microsoft 365, iCloud, Fastmail, Nextcloud and any other CalDAV server sync both ways. School, sports and team calendars can be added from their subscribe links, and holiday calendars from a list of countries.

Does my data go anywhere?

Your events, lists and photos stay on your server. Hearth only talks to the services you connect (like Google or Outlook), your own email provider if you set one up, and Open-Meteo for the weather, which only receives your town’s location.

How do updates work?

Run the install command again. It keeps your settings and data, downloads the newest version and restarts. Each update is built automatically from the code on GitHub.

Can the kids use it without accounts?

Yes. Family members are just names with a colour and emoji. Kids can tick off chores and see their stars on the wall display, and grown-ups manage everything from their own accounts.
